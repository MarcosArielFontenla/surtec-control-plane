# Skill: MVP Scope

## Objective

Define the smallest product scope that can validate the intended value.

## When To Use

- Starting a new product, feature, or internal tool.
- Reducing an oversized scope into a shippable first version.

## Procedure

1. Identify target user and core job.
2. Define must-have workflows.
3. Separate nice-to-have and later features.
4. Define measurable success criteria.
5. Identify overbuilding risks and missing assumptions.

## Output Format

- MVP goal.
- Target user.
- In scope.
- Out of scope.
- Success criteria.
- Risks and assumptions.
- Next validation step.

## Limits

- Do not turn MVP planning into a full roadmap.
- Do not include features without a clear validation purpose.
