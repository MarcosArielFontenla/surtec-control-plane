# Skill: Systematic Debugging

## Objective

Find and fix defects through evidence instead of guessing.

## When To Use

- A test fails.
- Behavior is unexpected.
- A bug report needs investigation.

## Procedure

1. Reproduce the issue.
2. Capture the exact command, input, expected behavior, and actual behavior.
3. Isolate the smallest failing case.
4. Form hypotheses and test them one at a time.
5. Identify root cause.
6. Apply the smallest fix.
7. Verify the original symptom and relevant regressions.

## Output Format

- Reproduction.
- Evidence collected.
- Hypotheses tested.
- Root cause.
- Fix.
- Verification.
- Remaining risks.

## Limits

- Do not patch without reproducing when reproduction is possible.
- Do not claim a fix without verification.
