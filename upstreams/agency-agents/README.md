# agency-agents Upstream

Repository: `https://github.com/msitarzewski/agency-agents.git`

This upstream is an inspiration catalog for agent definitions.

## Update Model

- No clone is created during bootstrap.
- Do not import the catalog wholesale.
- Preview candidate agents, select intentionally, transform to Codex TOML, and review.

## Risks

- External agent definitions may conflict with Surtec governance.
- Imported prompts may contain assumptions that do not fit Surtec projects.
