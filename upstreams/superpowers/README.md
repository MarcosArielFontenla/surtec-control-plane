# Superpowers Upstream

Repository: `https://github.com/obra/superpowers.git`

Superpowers is a development methodology reference for agentic coding work.

## Update Model

- No clone is created during bootstrap.
- Updates are monitored manually.
- Imported methodology changes must be reviewed before being adopted into Surtec workflows.

## Risks

- Workflow changes can affect agent behavior.
- Strict process requirements may conflict with specific user instructions, which take precedence.
