# Superpowers Usage

Superpowers is the preferred methodology for agentic development when installed.

## Core Workflows

- Brainstorming for shaping unclear ideas.
- Writing plans before multi-step implementation.
- Worktrees for isolated task execution.
- Test-driven development for behavior changes.
- Systematic debugging for defects.
- Code review before completion.
- Verification before claiming success.
- Finishing branches with human merge decisions.

## Surtec Rule

User instructions and repository governance remain highest priority. If a workflow asks for commits but the task says no commits, do not commit.

## Output Expectations

Agents should report:

- Summary.
- Files changed.
- Commands run.
- Tests run.
- Risks.
- Blockers.
- Next steps.
