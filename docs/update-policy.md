# Update Policy

Surtec Control Plane monitors upstreams but does not apply updates automatically.

## Paperclip

Paperclip updates require manual review of release notes, adapter compatibility, security impact, and operational changes.

## Superpowers

Superpowers updates require review of workflow changes and any effect on agent behavior.

## agency-agents

Agent definitions may be used as inspiration only. Imports must be selected, transformed, and reviewed.

## claude-for-legal-argentina

Legal reference updates require human legal review. Generated legal skills must preserve caveats and updated verification notes.

## Codex CLI

Codex CLI changes should be tested through dry-run tasks before real execution.

## Surtec Projects

Project updates happen in each project repository, not in this control plane. The control plane may create branches or worktrees only when explicitly asked.
