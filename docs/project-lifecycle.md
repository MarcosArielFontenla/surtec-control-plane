# Project Lifecycle

Surtec projects move through a controlled lifecycle.

## Stages

1. Idea.
2. Product scope.
3. Specification.
4. Implementation plan.
5. Branch or worktree creation.
6. Implementation.
7. Tests and validation.
8. Review.
9. Human merge.
10. Human-approved release.

## Control Plane Role

The control plane records project metadata, allowed agents, automation scripts, and execution policies. It does not replace the project repository.

## Human Decisions

Humans approve scope changes, merges, releases, legal conclusions, and upstream imports.
