# Argentine Legal References To Codex Skills Transform

This transform previews and builds Surtec legal skills from an optional reviewed legal reference upstream.

Legal transforms require human legal review before use.

## Commands

```bash
./transforms/legal-ar-to-codex-skills/preview.sh
./transforms/legal-ar-to-codex-skills/build.sh
```

`build.sh` is currently a guarded placeholder and requires `SURTEC_EXECUTE=1`.
