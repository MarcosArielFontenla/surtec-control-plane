# Paperclip Adapter Evals

This folder will contain evaluations for mapping Paperclip-like tasks into `TaskEnvelope`.

## Criteria

- Produces valid `TaskEnvelope` objects.
- Preserves task title, body, project, source, and metadata.
- Chooses conservative sandbox defaults.
- Does not depend on a real Paperclip API.
- Keeps Paperclip replaceable.
